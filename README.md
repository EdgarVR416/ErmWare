# ErmWare Landing Page

A responsive landing page for ErmWare, a Roblox executor tool.

## Features

- Fully responsive design that works on all devices
- Modern, sleek design with dark theme and red accents
- Interactive elements with smooth animations
- Mobile-friendly navigation with hamburger menu
- Particle effects and smooth scrolling

## Setup

1. Clone or download this repository
2. Open `index.html` in your browser to view the landing page

## Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies needed

## Project Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling for the landing page
- `script.js` - JavaScript for interactive elements and animations
- `background.jpg` - Hero section background image

## Resources Used

- [Font Awesome](https://fontawesome.com/) - For icons
- [Google Fonts](https://fonts.google.com/) - For Poppins font family

## Notes

This landing page was created using vanilla HTML, CSS, and JavaScript as requested, with no frameworks.

To fully complete the landing page, you should:

1. Replace `background.jpg` with a high-quality image related to ErmWare or Roblox
2. Link the download button to your actual software download
3. Update social media links to your actual profiles
